# Retail Purchase & Conversion Intelligence Platform
### Problem Statement 2: AI/ML-Powered Predictive Insight Dashboard

An enterprise-grade, full-featured retail decision-support platform that transforms historical customer transaction and session data into predictive purchase conversion intelligence, behavioral analytics, actionable customer segmentations, ground-truth outcome evaluation, explainable drivers, and conversational natural language executive insights.

---

## 1. Product Story & Dual-Mode Architecture

```text
               Input Shopper Dataset (CSV)
                           ↓
             Automatic Dual-Mode Detection
             (Is Revenue target present?)
             ┌─────────────┴─────────────┐
             ↓                           ↓
   [Mode A: Prediction]        [Mode B: Evaluation]
    Unlabeled session log       Target 'Revenue' extracted
             ↓                  & isolated (Zero Leakage)
             └─────────────┬─────────────┘
                           ↓
            Feature Preprocessing Engine
    (StandardScaler & OneHotEncoder handle_unknown='ignore')
                           ↓
            Production ML Classifier (Random Forest)
                           ↓
             Conversion Probability (0.0% – 100.0%)
                           ↓
     Fixed Intent Tiers (High / Medium / Low Intent)
                           ↓
     ┌──────────────────────────────────────────────────┐
     │ Deterministic Analytics & Evaluation Engine      │
     │ • Mode A: Cohort KPIs, Profiles, Segmentation    │
     │ • Mode B: Confusion Matrix, Error Profiling,     │
     │           Brier Score, Threshold Sensitivity     │
     └──────────────────────────────────────────────────┘
                           ↓
                 Structured Facts Layer
                           ↓
        ┌──────────────────┼──────────────────┐
        ↓                  ↓                  ↓
Streamlit Dashboard  Conversational Copilot  FastAPI REST API
 (Executive SaaS)   (Multi-Turn Dialogue)  (http://localhost:8000/docs)
```

### Core Trust & Safety Architecture:
> **The AI Copilot operates strictly on deterministic structured analytical facts generated by Python (`analytics_engine.py` & `evaluation_engine.py`). It never alters ML model weights and never hallucinates numbers or metrics.**

## 2. Platform Feature Areas

### 📊 Executive Overview
- **Mode A (Prediction Mode)**:
  - Headline KPIs: Total Sessions Scored, Predicted Conversions, Mean Conversion Probability, and High-Intent Opportunity Count.
  - Conversion probability distribution histogram with box-plot outliers.
  - Intent tier volume breakdown donut chart.
  - Geographic market conversion overview.
- **Mode B (Evaluation Mode)**:
  - Live vs Holdout Benchmark comparison table: ROC-AUC, F1-Score, Precision, Recall, Accuracy, Brier Calibration Loss.
  - Live Confusion Matrix breakdown (True Positives, True Negatives, False Alarms, Missed Conversions).
  - Actual observed conversion rate vs model predicted conversions.

### 🔍 Prediction Explorer & Session Detail
- Interactive search, filter by Intent Tier, Prediction Result (`Correct Purchase`, `False Alarm`, `Missed Conversion`, etc.), Country/Market.
- 1-click **CSV export** for marketing automation and CRM integration.
- **Session Detail Inspector**: Select any individual session to inspect its behavioral signals (`Recency`, `Frequency_log`, `Monetary_log`, `DistinctProducts_log`, `Tenure`) alongside deterministic behavioral interpretations and error diagnostics.

### 🎯 Outcome Evaluation & Calibration (Mode B Deep-Dive)
- **Confusion Matrix & Classification Breakdown**: 2x2 interactive Plotly heatmap with counts and percentages for all 4 quadrants, paired with business operational interpretations.
- **Behavioral Error Profiling**: Side-by-side behavioral comparison of Missed Conversions (FN) vs False Alarms (FP) vs Correct Predictions across Inactivity (Recency), Historical Spend (Monetary), and Frequency.
- **Decision Threshold Sensitivity Simulator**: Interactive slider (0.20 to 0.80) to simulate operational trade-offs between Precision, Recall, and Flagged Purchases in real time without modifying production model weights.

### 📈 Behavioral Analytics
- Inactivity lapse (`Recency`) vs. Conversion Probability with LOWESS trendlines.
- Customer lifetime spend (`Monetary_log`) vs. Catalog diversity (`DistinctProducts_log`) bubble distribution.
- Aggregated behavioral profiles table by Intent Tier.

### 👥 Segmentation & Action Center
- Multi-attribute business segmentation:
  - `VIP High-Value Champions`
  - `Fast-Track Conversion Prospects`
  - `Active Consideration Nudge`
  - `At-Risk Warm Leads`
  - `Lapsed High-Spenders`
  - `Dormant / Window Browsers`
- Concrete commercial action protocols for marketing, customer success, and merchandising teams.

### 🧠 AI Executive Insights & Conversational RAG Copilot
- Grounded factual synthesis generated strictly from deterministic cohort quantiles:
  - **Executive Summary**: 4 concise, high-level findings.
  - **Key Trends**: Inactivity thresholds and spending patterns.
  - **Conversion Opportunities**: Immediate revenue capture vs. lapse prevention.
  - **Recommended Actions**: Targeted commercial interventions.
- **Conversational RAG Copilot**:
  - Full multi-turn dialogue with memory (`st.session_state.copilot_messages`).
  - Dynamic quick prompt chips tailored to Mode A (Cohort Diagnostic, Retention Strategy, Driver Analysis) or Mode B (Evaluation Health, Missed Conversions, False Alarms, Threshold Trade-offs).
  - Every response includes **Verified Numerical Citations**.

### ⚙️ Model Governance & Explainability
- Holdout discrimination metrics: **ROC-AUC (0.793)**, **F1-Score (0.704)**, **Precision (67.4%)**, **Recall (73.6%)**, **Accuracy (70.5%)**.
- Business-level Feature Importance chart with render-time prefix aggregation (e.g. *Days Since Last Purchase*, *Customer Lifetime Spend*, *Catalog Variety*).
- Fixed threshold governance: `High Intent ≥ 0.7281`, `Medium Intent ≥ 0.5164` (derived once from holdout scores, never recomputed per batch).

## 3. Production REST API (`app/api.py`)

Interactive Swagger / OpenAPI docs available at `http://localhost:8000/docs`:

- `GET /health`: Operational readiness and artifact metadata.
- `GET /metrics`: Holdout metrics, cutoffs, and feature importances.
- `GET /schema`: Input feature contract.
- `POST /predict`: Real-time session batch scoring.
- `POST /simulate`: Counterfactual "What-If" behavioral shifts.
- `POST /evaluate`: Programmatic batch evaluation with confusion matrix, Brier loss, and error classifications.

## 4. How to Run the Project

### 1. Run Automated Test Suite
```bash
python -m pytest tests/test_pipeline.py -v
```
*Expected: 11 passed tests in ~14 seconds.*

### 2. Launch Streamlit Executive Platform
```bash
streamlit run app/app.py
```
*Open http://localhost:8501 in your browser.*

### 3. Launch FastAPI Microservice
```bash
python app/api.py
```
*Open http://localhost:8000/docs for Swagger documentation.*
